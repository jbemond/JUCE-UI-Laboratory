# Plateformes et limites

| Élément | Implémentation actuelle | Natif système |
| --- | --- | --- |
| Boutons, listes, curseurs | JUCE LookAndFeel | Non |
| Barre de titre | DocumentWindow | Oui si supporté |
| Barre de menus | MenuBarComponent | Non ; macOS à développer |
| Dialogues de fichiers | FileChooser | Option native selon OS |
| Thèmes Windows/macOS/GNOME/KDE | Couleurs et formes inspirées | Non |

Un thème imitant macOS ou Windows n'est pas identique à un ensemble de widgets natifs.
